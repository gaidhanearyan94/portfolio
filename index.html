Second year, first real project — many more coming.

I got into AI Engineering because I wanted to understand what's actually happening behind the tools everyone talks about. Python gave me the speed to experiment, and C taught me to respect memory, pointers, and the cost of every line I write.

My first minor project turned that curiosity into something practical: a Personal Finance Tracker that doesn't just log your expenses, but uses AI to tell you something useful about them. It's small, but it's mine end-to-end — from the logic to the insights.

Right now I'm splitting my time between strengthening data structures & algorithms in C, and going deeper into machine learning fundamentals in Python. This site will grow project by project as I do.
